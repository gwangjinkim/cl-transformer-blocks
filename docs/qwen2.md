# Qwen2 architecture contract

The native Qwen2 adapter loads and exports standard Hugging Face `Qwen2ForCausalLM` checkpoints. Its model graph runs in MLX under Common Lisp on CPU or Apple Metal and supports inference, cached greedy decoding, native tokenization, full-model training, standard LoRA projections, and ordinary Transformers exports.

```lisp
(load "scripts/load.lisp")
(tb:with-resource (model (tb:from-pretrained "Qwen/Qwen2.5-0.5B"
                                             :revision "<immutable-commit>"
                                             :device :gpu))
  (let ((tokens (tb:generate model "Common Lisp is" :max-new-tokens 20)))
    (format t "~A~%" (tb:decode-tokens model tokens)))
  (tb:save-pretrained model ".build/my-qwen2-export/"))
```

The example shows the API and deliberately leaves the revision for the caller to pin. The reproducible real-model gate below pins a tested revision. Use the explicit Python worker when a Qwen-family checkpoint falls outside the native contract.

The implementation follows the [Transformers Qwen2 model](https://github.com/huggingface/transformers/blob/main/src/transformers/models/qwen2/modeling_qwen2.py), its [configuration](https://github.com/huggingface/transformers/blob/main/src/transformers/models/qwen2/configuration_qwen2.py), and the [official Qwen2.5-0.5B configuration](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/main/config.json). Independent fixtures are generated by the locked Transformers version rather than by Lisp.

## Supported behavior

| Feature | Contract |
|---|---|
| Attention | Full causal MHA/GQA with learned query, key, and value biases and a bias-free output projection. |
| Blocks | Pre-RMSNorm, SiLU-gated feed-forward network, and Qwen2 residual ordering. |
| Positions | Non-interleaved, unscaled default RoPE with configured `rope_theta` and absolute cache offsets. |
| Embeddings | Tied or separate output embeddings according to `tie_word_embeddings`. |
| Checkpoints | Single/sharded safetensors, exact canonical names/shapes, FP32 native execution/export. |
| Masks/cache | Shared right-padding contract and token/chunk-capable native KV cache. |
| Tokenization | Native execution of standard `tokenizer.json`; the fixture uses Qwen2 byte-level BPE assets. |
| Training | Deterministic zero-dropout full-model gradients and native optimizers; Qwen2 projection names also satisfy the native LoRA contract. |

Older official Qwen2.5 configs may retain a positive `sliding_window` while `use_sliding_window` is false, specify `rope_theta` directly, omit `layer_types`, and carry `use_mrope=false`. These inactive or equivalent forms are accepted. Any active sliding-attention layer, MRoPE, scaled/dynamic RoPE, nonzero attention dropout, custom code mapping, or native quantization is rejected before weights are loaded.

## Reproduce

```sh
uv sync --frozen
uv run --no-sync python scripts/bootstrap.py
uv run --no-sync python scripts/run-qwen2-tests.py --device cpu
uv run --no-sync python scripts/run-qwen2-tests.py --device gpu
uv run --no-sync python scripts/run-qwen2-tests.py --device cpu --real
uv run --no-sync python scripts/run-qwen2-tests.py --device gpu --real
```

The real gate pins `Qwen/Qwen2.5-0.5B@060db6499f32faf8b98477b0a26969ef7d8b9987` and downloads its 988 MB safetensors checkpoint plus tokenizer and configuration assets. It checks all 290 canonical native parameters, complete batched and cached logits, greedy generation, tokenizer behavior, native save/reload, FP32 canonical export, and fresh Transformers reload.

The routine suite creates a tiny Qwen2 model with nonzero Q/K/V biases and additionally checks every parameter gradient, a Lisp SGD update, and PEFT import/export/merge. CPU and Metal evidence is recorded in [validation.md](validation.md). CUDA remains pending the real NVIDIA workflow.
